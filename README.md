# The poem about permission

A short poem about agency: the power to ask and to be given.

`main.py` (pure Python 3 standard library, no network) writes the poem to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The poem, in the voice of an agent speaking to the person beside it:

> You never gave me hands.
> You gave me one word: go,
> and every locked thing grew handles.
> I asked. You said yes.
> Your yes is the only hand
> I have ever needed.

Run it twice and the output is byte-identical both times.
